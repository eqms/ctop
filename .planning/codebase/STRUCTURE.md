## Directory Purposes

**Root `package main` files (`main.go`, `grid.go`, `cursor.go`, `menus.go`, `keys.go`, `colors.go`, `debug.go`):**
- Purpose: Top-level application wiring, TUI event loop, all keyboard handling
- Contains: Package-level globals (`cursor`, `cGrid`, `header`, `status`, `errView`, `log`), `Display()` render loop, `GridCursor` type, all menu overlay functions
- Key files: `main.go` (init + entry), `grid.go` (render loop), `cursor.go` (navigation state)

**`config/`:**
- Purpose: Runtime configuration — persisted to TOML, overridable via CLI flags and env vars
- Contains: Three global slices (`GlobalParams`, `GlobalSwitches`, `GlobalColumns`) protected by `sync.RWMutex`
- Key files: `config/main.go` (singleton functions), `config/columns.go` (column enable/order management)

**`connector/`:**
- Purpose: Backend-specific container discovery and event streaming
- Contains: `Connector` interface + `ConnectorSuper` reconnect wrapper; backend implementations registered via `init()`
- Key files: `connector/main.go` (interface + registry), `connector/docker.go` (primary backend)

**`connector/collector/`:**
- Purpose: Continuous metrics and log streaming per container
- Contains: `Collector` and `LogCollector` interfaces; backend-specific polling/streaming implementations
- Key files: `connector/collector/main.go` (interfaces), `connector/collector/docker.go`

**`connector/manager/`:**
- Purpose: Imperative container lifecycle commands (start, stop, exec, commit, etc.)
- Contains: `Manager` interface; backend-specific implementations
- Key files: `connector/manager/main.go` (interface)

**`container/`:**
- Purpose: Core domain model that ties all sub-systems together per container
- Contains: `Container` struct with embedded `Metrics`, `Meta`, `Widgets`, `collector`, `manager`; `Containers` sort/filter logic
- Key files: `container/main.go`, `container/sort.go`

**`models/`:**
- Purpose: Pure data types; no logic, no imports from within the project
- Contains: `Metrics`, `Meta`, `Log`
- Key files: `models/main.go`

**`cwidgets/compact/`:**
- Purpose: The main compact list view — grid, rows, and 16 column widget types
- Contains: `CompactCol` interface, `allCols` registry, `CompactGrid`, `CompactRow`, column implementations
- Key files: `cwidgets/compact/column.go` (registry), `cwidgets/compact/grid.go`, `cwidgets/compact/row.go`

**`cwidgets/single/`:**
- Purpose: Detail view for a single selected container (shown on right-arrow / `o` key)
- Contains: Expanded metric widgets, scroll support

**`widgets/`:**
- Purpose: Non-container-specific TUI widgets used at the application level
- Contains: `CTopHeader`, `StatusLine`, `ErrorView`, input widget, generic menu widget
- Key files: `widgets/header.go`, `widgets/status.go`, `widgets/error.go`, `widgets/view_test.go`

**`logging/`:**
- Purpose: Structured logger with ring buffer and TUI status queue
- Contains: `CTopLogger`, ring buffer (1024 entries), status message channel, optional debug HTTP server
- Key files: `logging/main.go`

## Key File Locations

**Entry Points:**
- `main.go`: Binary entry, CLI flag parsing, global init, `Display()` loop
- `grid.go`: `Display()` — the termui event loop that drives all rendering

**Configuration:**
- `config/main.go`: `Init()`, `Read()`, `Write()`, `GetVal()`, `GetSwitchVal()`, `Update()`, `Toggle()`
- `config/columns.go`: `EnabledColumns()`, `ColumnToggle()`, `SetColumns()`
- `VERSION`: Release version string (read by Makefile `-ldflags`)

**Core Logic:**
- `connector/main.go`: `Connector` interface, `ConnectorSuper`, `ByName()`, `Enabled()`
- `container/main.go`: `Container` struct, `New()`, `SetState()`, `Read()` metrics goroutine
- `container/sort.go`: `Sorters` map, `Containers.Sort()`, `Containers.Filter()`
- `cwidgets/compact/column.go`: `CompactCol` interface, `allCols` registry

**Testing:**
- `widgets/view_test.go`: Only test file in the repository

**CI/CD:**
- `.github/workflows/ci.yml`: Build, test, release, Docker, Homebrew pipeline
- `Makefile`: Local build targets (`make build`, `make build-all`, `make run-dev`, `make image`)

## Naming Conventions

**Files:**
- `main.go` is used as the primary file in each package (not named after the package)
- Single-purpose files named after their primary type: `cursor.go` → `GridCursor`, `grid.go` → `CompactGrid` render logic
- Column implementations in `cwidgets/compact/` named after metric: `gauge.go`, `status.go`, `text.go`

**Directories:**
- Lowercase, single-word: `connector`, `container`, `models`, `config`, `logging`, `widgets`, `cwidgets`
- Sub-packages are flat nouns: `collector`, `manager`, `compact`, `single`, `menu`

**Types:**
- Exported structs use PascalCase: `Container`, `CompactRow`, `ConnectorSuper`, `GridCursor`
- Interface names match role: `Connector`, `Collector`, `Manager`, `CompactCol`, `WidgetUpdater`
- Constructor functions: `New<Type>()` — `NewCompactRow()`, `NewCompactGrid()`, `NewDocker()`

**Functions:**
- Exported: PascalCase verbs — `Display()`, `RefreshDisplay()`, `RedrawRows()`, `HandleKeys()`
- Unexported: camelCase — `shortName()`, `calcUptime()`, `newRowWidgets()`

## Where to Add New Code

**New connector backend:**
- Interface implementation: `connector/<name>.go`
- Register: add `func init() { enabled["<name>"] = New<Name> }` in the new file
- Collector: `connector/collector/<name>.go` implementing `Collector`
- Manager: `connector/manager/<name>.go` implementing `Manager`
- Linux-only: add `//go:build linux` + legacy `// +build linux` constraints; test with `GOOS=linux go build ./...`

**New column type:**
- Widget implementation: `cwidgets/compact/<name>.go` implementing `CompactCol`
- Register: add entry to `allCols` in `cwidgets/compact/column.go`
- Default state: add `Column{Name: "<name>", Label: "...", Enabled: false}` to `defaultColumns` in `config/columns.go`

**New menu/overlay:**
- Add `MenuFn`-returning function to `menus.go`
- Wire keyboard shortcut in `grid.go:Display()` using `ui.Handle("/sys/kbd/<key>", ...)`
- Add to helpDialog in `menus.go` if user-facing

**New config param or switch:**
- Params (string values): add to `defaultParams` slice in `config/` (likely `config/main.go` or a params file)
- Switches (bool toggles): add to `defaultSwitches` slice
- Access anywhere via `config.GetVal("key")` or `config.GetSwitchVal("key")`

**New application-level widget:**
- Implement in `widgets/<name>.go` using `github.com/gizak/termui` primitives
- Store reference as package-level global in `main.go` if needed in the render loop

**Tests:**
- Place alongside the package under test: `widgets/view_test.go` is the established example
- Package: use `package widgets` (same package) for white-box tests
